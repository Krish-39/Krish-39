# Sample Website

This repository includes a simple static website consisting of an `index.html`, `style.css`, and `script.js`. These files demonstrate basic HTML, CSS, and JavaScript usage and provide a starting point for creating your own website.

The example now includes a dark mode toggle and a small contact form to illustrate common interactive features.

## How to view the website

1. Clone the repository or download the files to your computer.
2. Open the `index.html` file in your web browser. No additional setup is required.

### Features

- **Greeting Button** – click the button on the home section to see a browser alert.
- **Dark Mode** – use the "Toggle Theme" button in the header to switch between light and dark themes.
- **Contact Form** – submit the contact form to display a thank-you message.

Feel free to modify the files and experiment with your own content and styling.
